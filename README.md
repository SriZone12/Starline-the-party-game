# Starline

A 2–15 player, same-device party game where players connect up to 69 numbered stars with neon lines and unlock a dare whenever a line crosses another line or touches the wrong star.

## Run Locally

**Prerequisites:** Node.js and npm. No API key is required.

1. Install dependencies:
   `npm install --legacy-peer-deps --no-package-lock`
2. Run the app:
   `npm run dev`

Open http://localhost:3000.
